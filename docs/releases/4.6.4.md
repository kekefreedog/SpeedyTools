# SpeedyTools 4.6.4 — Structure templates

For Minecraft 1.8 with Forge 1.8-11.14.3.1450. Install the same mod version on clients and multiplayer servers.

- Capture structures by selecting two corners with the new Structure Capture wand.
- Save, overwrite, rename, share, trash and restore templates; inspect dimensions and anchors.
- Browse World and Computer libraries, including template miniatures in the creative inventory. Computer templates can be reused across worlds and servers, subject to server import permissions.
- Move, rotate and mirror placement previews; hold right-click to build with progress animation. Left-click cancels the preview. Default shortcuts: B for library, R for rotation and V for mirroring.
- Add a pixel-style wand icon and refine its model to remove overlapping faces.
- Shorten messages and wrap inventory tooltips, with additional details available using Shift.
- Fix rail directions when rotating or mirroring structures, including curves, slopes and powered rail states.

Multiplayer storage and placement are server-controlled. Computer imports require operator permission by default. Templates preserve blocks and block-entity data; entities and scheduled ticks are not included. Some modded blocks may require additional rotation support.
